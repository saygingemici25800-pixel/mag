# mag-starter
Claude Code'a bu klasörle gir. Sıra:
1. `mag-burger.md` → spec (tek kaynak)
2. `proto/proto.html` → referans prototip, tarayıcıda aç (tek dosya, her şey gömülü)
3. `proto/proto.template.html` → aynı prototip, görseller base64 yerine __PLACEHOLDER__ (okuması kolay)
4. `assets/cut/` → 5 burger cutout (WebP, 480px) · `assets/hero/` → stüdyo kareleri
5. `promptlar/` → ChatGPT görsel promptları

Açılış promptu spec'in 10. bölümünde.
